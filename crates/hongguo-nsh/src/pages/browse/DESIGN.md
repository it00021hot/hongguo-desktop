# 找剧与搜索联想

主任务是输入剧名后直接进入对应剧集，或选择词条查看搜索结果。筛选浏览与已提交搜索继续共用结果区；搜索草稿、提交词、焦点、IME 组合、联想开态和当前条目由找剧页唯一持有。联想最多显示八条，只有停输 300ms、至少两个字符、仍处于浏览模式且响应属于当前草稿时出现。

交互与布局以 Tauri `browse-page.tsx` / `suggest-row.tsx` 为准：Popover 锚定输入框，保留输入焦点；上下键循环当前可见八条，Enter 选择，Escape/失焦/外点关闭。IME 组合期间不接管方向键和 Enter。带 seriesId 的条目进详情，纯词条提交搜索。封面仅在 cover 非空时显示，命中片段使用 warm 语义色，rich 标题加粗；有摘要才显示第二行。输入继续使用共享 field，弹面与行在独立 ui/search_suggestions.rs 中统一样式。

| 状态变化                     | 工具与令牌                                                                    | 减少动态效果     |
| ---------------------------- | ----------------------------------------------------------------------------- | ---------------- |
| 按钮 hover/pressed/focus     | 共享按钮的 FAST_MS/按压缩放/语义 focus ring                                   | 不缩放、即时换色 |
| 当前联想条目变化             | accent 背景与 FAST_MS 颜色过渡；行不移动                                      | 即时换色         |
| 联想打开/关闭                | Popover starting/ending opacity、PRESS_SCALE、FAST_MS，从输入框下沿展开       | 即时显示/隐藏    |
| 草稿变化、命中片段与摘要变化 | 保留输入焦点；等待实际 debounce，请求更替取消旧任务；内容即时呈现以免干扰输入 | 相同             |
| 筛选展开/退出搜索            | 保留现有单滚动区、按钮和状态反馈                                              | 相同             |
| 离开后返回/筛选结果更换      | 同会话恢复草稿、筛选与原滚动位置；筛选或身份变化时即时回顶，不播放滚动动画    | 相同             |
| 加载/失败/空联想             | 没有可选条目时不打开弹面；不覆盖现有结果或显示虚构选项                        | 相同             |
| 拖放/连续播放/声音           | 无；找剧页面没有这些交互                                                      | 无               |

验证先用手动时钟的 Headless 回归覆盖 debounce、上限、键盘、IME、过期响应、词条/剧集分流和取消，再在同一个离线 LayoutPreview 根窗口检查明暗开态、外点、输入焦点与窄窗口。原生 IME 与屏幕阅读器不能由 Headless 结果替代，未实测须保留限制。

联想两套预览共享 `preview/fixtures/search-suggestions.json`，封面标记由各预览装配为同一张本地帧，不分发影视样本。Tauri 参照组件的两处缺陷已在本轮最小修复：直接可显示的封面保留原地址，仍用 isRenderableCover 的离线闸门；Popover 宽度使用本地 Radix 已实现的 `--radix-popover-trigger-width`（映射到实际 Anchor 宽），不引用不存在的 anchor 别名。修复前的实际浏览器回归为 243.656px 窄弹面且无封面，修后为输入等宽 864.281px、320px 高、40×54 封面成功加载。忽略的 `target/tauri-layout-reference/suggestions-red.log`、明暗同名 PNG/JSON 保留证据，未通过 mock 修改组件结果。

全页补充动效：首次加载显示与 Tauri 相同十张封面/两条文字骨架，用原生 animate-pulse，减少动态效果时静止；有结果的重新筛选使用 CHROME_MS 透明度过渡与实际 pending 禁点，不挪动内容。提交中的搜索图标用原生 animate-spin，减少动态效果显示静态等待图标。筛选组用 nsh-base ToggleGroup/Toggle 的键盘漫游与 pressed 语义，选中边框/背景沿 FAST_MS；取消选择恢复“全部”，已选数量徽标即时更新。续页在原有父滚动区到末端时触发，保留已有卡片，加载状态只占页尾状态行，不重播整页动画。

结果归属使用 Query 的筛选/提交词 Scope，而不是“Resource 是否仍保留一个旧值”：换词/换筛选时不把旧列表冒充新结果，首次响应前显示骨架；同 Scope refetch 保留列表加刷新遮罩；续页保留之前条目。搜索少于18条且真实 hasMore/cursor 可前进时自动续拉，普通浏览用虚拟列表近尾回调；pending、错误、相同/退回 cursor 和终页均阻止重复派发。搜索标签与热度分别按原组件 subTitle 首段、formatCountPrecise 的语言语义兜底。

已验证：9项 Headless 覆盖联想、筛选计数/清除、新结果骨架/隔离、少量搜索两页自动合并及终页停止；原生联想两主题完整流程2/2通过，包含词条提交、退出、外点和 Escape。Tauri 基线另修实际键盘按隐藏第9/10条循环的问题：8条上限移到派生数据，让显示与键盘共享同一集合；真实10条 fixture 的 Up 红证据为无可见 active，修后落到第8条。原生 IME 和辅助技术仍没有真机实测，Headless 只验证组合状态契约，不据此宣称系统输入法已验收。全局 macOS 原生字体平滑与浏览器 antialiased 的字重视觉差异沿用既有记录，不用改变设计字重掩盖。
