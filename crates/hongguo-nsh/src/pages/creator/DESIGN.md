# 创作者主页与详情入口

详情页在简介之后呈现实际main_creator_users头像/姓名/角色，只有user_id非空的筹码能进入主页。主页资料与作品分开请求，资料失败不遮掉作品；点击作品始终进入详情。作品使用官方API的series_id，游标原样续传，不能按集号或video播放地址猜链接。

真实规格来自CreatorHomePage与SeriesDetailPage：主页max-width1152px、水平32/垂直24；返回按钮32高/左偏8；资料头距返回16，头像64圆形，姓名20/28 bold，简介14/20最多两行。作品标题距资料24，网格上距12、间距12，2/3/4/5列对应640/1024/1280窗口断点，封面3:4、14圆角。底部覆盖标题最多两行与12px集数/热度/播放统计，使用固定视频字幕语义色与向上渐变，保留原图覆盖语义，不另画普通信息卡。

详情筹码为28头像/无图UserRound、姓名12 medium、角色10，左右4/12、上下4、1px语义边框、全圆角，筹码间12。没有user_id的条目保留资料但禁用；无头像回落图标，不虚构肖像。空创作者集合不留下额外段落间距。

页面持user_id/游标/累计作品及活跃状态，资料和作品资源各自持loading/error。资源销毁取消桥接请求，旧uid/身份结果不能替换当前页。翻页只在真实hasMore且cursor可前进时进行，按series_id稳定去重/回收；虚拟列表按钮读取当前位置的当前作品，不捕获初次分配的槽索引。Header total保留首个响应口径，不用已加载数量冒充作品总数。

| 状态变化                              | 工具/令牌                                               | 减少动态效果     |
| ------------------------------------- | ------------------------------------------------------- | ---------------- |
| 返回/创作者筹码 hover、pressed、focus | 共享Button/FAST_MS、语义focus ring                      | 即时换色、无缩放 |
| 作品封面hover                         | 图片opacity至0.8，FAST_MS，卡片不移动                   | 即时透明度       |
| 资料与作品首次加载                    | 原生animate-pulse的头像/文字/封面骨架                   | 静止占位         |
| 翻页                                  | 同一父滚动区尾部真实loading spinner、已有作品不闪回骨架 | 静态进度图标     |
| 资料失败/作品失败/空作品              | 资料独立缺省、作品本地化错误+重试/空态                  | 相同             |
| 页面进退                              | Navigation/stack既有规则，不手写隐藏或Portal            | 跟随系统         |
| 拖放/声音/手势                        | 本页无这些交互                                          | 无               |

头像/封面URL归一使用独立image_url门面：仅对仓库证实的CDN/模板做规则，签名query保持字节不变，不生成Tauri专属代理地址、不改签名模块。离线QA禁止外部资源；共享非媒体fixture只在装配时替换成本任务本地帧，不提交影视图片。

验证先Headless覆盖详情入口/无id禁用、资料失败仍显示作品、游标续页/去重/终止、作品进详情及虚拟行回收，再使用相同JSON在真实Tauri组件与同LayoutPreview捕1280×840明暗图。实际官方资料请求、移动端、系统读屏与真实头像解码单独说明范围，不用离线fixture替代业务验收。

已完成的离线证据：页面/分页6项、详情入口2项、图片 URL3项通过；Creator.test 原生明暗2项通过，同JSON原Tauri两图0异常/0外部请求。资料头 x256/y116/64高，作品标题 y204，5列卡 y240、188.797×251.75，与原组件相同；188宽统计文本真实换行32高。双方保持设计400字重，系统文字平滑造成字形粗细与局部换行差异，不用降低字重掩盖。Creator作品点击现在携带完整来源快照，真实解析失败才走未上线降级，普通成功分集优先。
