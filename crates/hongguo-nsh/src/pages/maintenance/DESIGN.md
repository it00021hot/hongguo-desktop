# 合并与磁盘清理

用户先选择已下载剧集、校验编码与磁盘余量，再启动 quick/compat 合并；任务记录持续呈现真实状态，完成后定位产物，删除记录前确认且先取消仍在运行的任务。磁盘页统计的是已下载文件，不把兼容缓存混在下载大小中；按剧搜索，删除一剧文件沿用原 Tauri 直接操作，清空全部必须确认。

布局直接按生产 MergePage/StoragePage：父内容单滚动，768px 最大外宽、24px 内边距、卡片间16px；卡片沿共享 form_surface，标题16px/semibold、内容间距16px，表单 label14px/medium 与控件间8px。合并选剧框36高、模式Tabs横向等分，兼容警告使用真实preflight，不用默认0冒充未知余量。任务/剧集行有边框与8px内间距，名称截断，尺寸用12px等宽或tabular数字。储存总量24px/semibold，右侧清空操作为destructive。

状态所有权：页面持选择、输出草稿、模式偏好、搜索、确认及pending；服务资源持候选/校验/任务/占用快照，后台读写经共用runtime阻塞池，界面不做磁盘或数据库I/O。effectiveMode从实际codecConsistent派生，显示和提交同源；保存或删除失败保留现场并显示本地化错误。真实进度经ServiceEvent输入，不用定时重载。数据来源和固定fixture共享同一个presentation，预览仅更新本地fixture与intent反馈，不调用磁盘/网络/系统打开操作。

| 状态变化                               | 原生工具与令牌                                                 | 减少动态效果         |
| -------------------------------------- | -------------------------------------------------------------- | -------------------- |
| 按钮/输入/select hover、pressed、focus | 共享控件FAST_MS与语义focus ring                                | 无位移、即时换色     |
| 模式选择                               | nsh-base Tabs/Tab，受控effectiveMode，颜色沿FAST_MS            | 即时换色             |
| 任务进度                               | 真实percent更新原生Progress，文本tabular，不让整页重新入场     | 即时更新             |
| 首次加载/失败/空列表                   | 真实loading、错误、空态，不把未读数显示为0                     | 相同                 |
| 删除确认                               | nsh-base alert dialog的焦点、Escape、取消/确认语义；不手写遮罩 | 使用系统减少动态效果 |
| 筛选结果/任务增删                      | 按稳定id更新，同一个父滚动区，不额外引入动画                   | 相同                 |
| 拖放/声音/手势                         | 页面没有这些能力                                               | 无                   |

验证：先Headless回归模式强制兼容、选择/输出名派生、繁忙输出防重、取消不执行删除、清空确认、过滤和删除后占用同步；再复用真实Tauri组件与同一非媒体JSON fixture捕1280×840明暗图。所有系统对话框与文件定位仅描述实际验证范围，不能用fixture动作当业务完成。

已完成5项Headless和4项macOS原生明暗完整流程，截图在target/nsh-preview与真实Tauri原组件同名对照。主尺寸1280×840；合并正常校验卡x392/y68/720×432、任务卡y516/720×276，来源DOM记录title16px/24px行高、Select36px、Tabs36px/p3。详情为空的输出框保持无占位，不重复字段标签。主题/字体沿语义角色；保留已证实的CoreText与浏览器字体平滑视觉差异，不调字重兜底。

文件/数据库工作在后台阻塞池；候选、校验和占用以已完成输入的id/路径/标题作为响应键，下载中的普通进度不会触发磁盘重扫。合并任务跟随统一merges revision；行内值为稳定Memo绑定，进度变化不重建整行。删除可能在部分文件移除后因保存失败报错，仍重读真实占用并保留错误。预览仅本地JSON与状态更新；未执行真实下载文件删除、合并、系统路径定位，也不把macOS预览扩称其它平台验收。
