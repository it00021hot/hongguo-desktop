# 历史与下载列表

对照真实 Tauri 的 `history-page.tsx`、`tasks-page.tsx`、`task-row.tsx`，不从通用海报网格推断布局。
生产装配和离线预览共用 `history::content`、`tasks::content`，样式集中在 `ui/library.rs`。
固定数据与审查时的 `target/tauri-layout-reference/library-reference.ts` 一致；本地视频帧仅作为预览海报，
不提交图片或临时 React 参考模块。预览不创建 Session，不访问数据库、下载目录或网络。

历史页使用 p16/gap12、匿名提示、三项过滤、240×32 桌面搜索框、管理入口、p12/gap16 的横卡。
海报固定 72×96，标题单行，进度徽标与相对日期同行，右侧继续播放。到达最后一集即算已看完，
与该集的片内观看比例无关；总集数未知不算看完。标题与 seriesId 均参与搜索。

下载页使用 p24/gap16，队列统计与六个 outline 操作位于同一可折行工具栏。
卡片内固定复选框、集数、状态、大小和操作列，剧名占剩余空间；操作列按真实两个 36px 按钮的
最小内容宽度 92px 排布。窄容器由实际 `on_layout` 测得可视宽度，内容不足时保留与 Tauri DOM
实测相同的最小列宽（Tauri 原表共611.734px），大小列保留源 `w-32` 的128px，
使原生等宽字体完整显示单位，原生表最小宽615.328px；显式横向 Scroll 供用户查看操作列。
运行中显示进度及已下载/总大小，失败展示原错误翻译。
完成/停止使用与 Tauri 相同的 success/warning 语义颜色，禁用状态不替换为伪操作。

记录体使用 NSH 的虚拟列表；单元绑定始终读取 `Position.index()`，不记住初次挂载的业务对象。
数据暂时没有对应行时按 Option 隐藏、操作检查当前 Some，禁止用陈旧对象兜底。
过滤或重排依赖领域 ID 保持身份。管理选择存放在列表外的按 ID 集合，
不会因行回收串到另一条记录；全选与混选只根据当前数据计算。复选框和进度使用 nsh-base 语义组件。

本组动效：按钮继承共享 hover/pressed/focus/disabled 及减少动态效果策略；筛选结果、计数、进度
即时更新，不为频繁变化的表格或列表播放入场/重新排列动画。行 hover 仅改变边界/弱背景。

生产历史按身份读取真实数据：匿名读本地 Store；登录后按官方返回游标取云端历史，保留 vid 与
1 起集号用于云端删除，重复剧按首条合并，游标不前进直接报错。身份版本不匹配时不显示资源旧值。
管理选择在页面内按剧 ID 保存；确认后才调用对应删除，失败保留选择，成功退出管理并刷新。
异步续播复用播放器档案解析/落库入口，使用历史集号，并检查当前路由及身份，避免离页后突然跳转。

下载恢复/暂停/停止/重试、删除、扫描均调用已有 service。移除确认显示完成数、可释放大小以及
默认关闭的「同时删除本地文件」，确认回调显式携带该选择；取消不派发。桌面打开目录使用公开
reveal_path，并显示真实错误；Android/iOS 导出当前完成任务的文件到系统选择的位置，
按任务 ID 选择产物，取消静默、失败反馈、成功提示。
Store、扫描与文件删除在共用 runtime 的 blocking 任务执行，不阻塞界面。生产和离线预览共用
同一确认组件与展示逻辑；预览只改变自己的内存数据，不能作为真实远端/文件系统验证。

确认动效：NSH 原生 Modal 的 Fade 进出，减少动态效果使用 None；200ms 过渡与共享按钮
hover/pressed/focus 保持一致；取消/Escape 不提交，确认关闭浮层后进入真实 pending 状态。
移动真机、安全区、大字体、屏幕阅读器和文件管理器错误流程仍待验。

检查：过滤模型两项回归通过；另有真实长列表回收回归，历史滚动后续播当前 ID，
任务选择经过滚出/滚入后仍按身份保存，均已通过。1280×840 深浅两页四项离线预览通过，
已目检与真实 Tauri 的卡片及表格主几何。窄480×840明暗复验两项通过，六个工具按钮按
真实参照分成4+2两行，表格y184，字节单行且单位完整。分别目检两主题滚动前/后四张图，
右侧操作由框外移入，点击后有纯本地预览回显，反向滚动恢复原位。
