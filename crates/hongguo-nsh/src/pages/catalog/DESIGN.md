# 推荐页播放与状态

正式首页复用 player::embedded，推荐流不是海报目录。频道进入全窗顶栏，手机保留可触控频道行。
源内保留频道游标与已接收条目；向上/下切剧，接近末尾读取下一页。进入详情后暂停，返回时继续当前播放器实例。
剧集档案先读本地，缺失才解析并持久化，起点取实际存在的续播集，不臆造第1集。

| 变化         | 实现                                                        | 验证                                                                       |
| ------------ | ----------------------------------------------------------- | -------------------------------------------------------------------------- |
| 切频道/换剧  | 共享顶栏 selected/hover/focus；后台请求归页面 resource 所有 | 待真实播放                                                                 |
| 起播/换源    | 复用生产播放器的独立视频平面与状态覆盖层；不复制控件        | macOS 正式入口起播、暂停、实际倍速、切集与清晰度切换通过                   |
| 隐藏/返回    | owner_route=Catalog，共享播放器生命周期暂停与进度落盘       | macOS 离开首页经历史返回，同集续播与实际时间推进通过；系统后台生命周期未验 |
| 加载/失败/空 | 共享状态与重试，真实错误可见；已有剧保留到新目标就绪        | 待真实播放                                                                 |

离线布局截图只能证明共享展示层。真实源证据见 `validation/playback`；频道切换与切剧仍需补验，
不能把同集切换清晰度或下一集当作频道切换通过。
