# 详情、来源档案与未上线状态

生产与离线预览共用 `presentation::render`；来源页通过 `DetailPrefill` 保留实际剧集 id、标题、封面、标签、简介。普通 `Detail(id)` 保持原入口；两种详情按 id 复用导航栈位置，后退仍回来源页。导航的父分区与侧栏选中分开：详情/创作者不选中任何侧栏项，Player 选推荐。

分集仍先调用现有 resolver，只有真实成功结果进入 registry/store。来源快照只在没有成功档案且解析失败后派生为零集视图，不写数据库、不伪造可播放的集号。无来源快照的解析失败保留错误和重试。已有真实分集在刷新失败时仍优先，不能被快照替换。元信息独立失败时有来源才降级为来源头部；登录身份改变重新请求元信息，让实际演职员资料跟随账号。

未上线动作使用原页面“即将上线”和预约/取消预约，隐藏播放及不适用的收藏/点赞/追更。预约成员从现有线上/待上线两个全集 API 获取，写入仍调用原 `reserve_series`，匿名请求打开统一账号入口。写入单飞；错误保留之前成员状态，旧账号异步结果不能修改当前账号。成功通知统一 library revision，无独立事件泵、轮询或 UI 磁盘操作。预览仅更改本地状态。

布局逐项取自 `SeriesDetailPage`：正文 max1152，桌面水平32/垂直24；小于768水平16/垂直16、底留144。海报按窗口断点176/112，间距32/12；标题24/33与18/24.75（实际leading-snug=1.375），不能以桌面设备类型代替窄窗判定。窄窗顶部保留全宽开播，底部仅收藏/点赞，原生桌面按钮40高/左右16/上下10，栏位在50高 BottomNav 上方留6。实际手机按钮保留48触摸尺寸。正文滚动不移动动作栏，未上线不显示此栏。

演职员详见 Creator DESIGN；剧情仅非空时显示，14px/22.75px（leading-relaxed=1.625），超过48字才给展开，展开后不制造原页面没有的折叠按钮。零集选集显示原空态文案，其Empty桌面md:p12优先于基础py10，故48px而非40px。徽章沿实际基线，含透明1px边，零集仍为“全0集”而不是自造新徽章文案。日历来源沿原CalendarRow传recTags，相关推荐传tag/videoDesc，不能拿category替换真实传参。

动效沿已有 Navigation、Button 和 focus ring，不增加位移/缩放。动作栏采用公开背景透明与8px backdrop blur；减少动态效果时无额外动画。失败、预约中、已预约、空分集均有本地化文字，颜色只用语义令牌。

回归先复现带来源仍显示空标题/错误重试/开播的旧行为，再验证来源头部、零集动作及预约切换。窄窗旧版本缺动作栏的红证据单独保留。原 Tauri 完整生产组件使用同 creator JSON、固定解析失败缓存，0外部请求；NSH 用同 LayoutPreview 验明暗/480宽。离线预览不代替真实官方预约、账号或手机验收；浏览器与原生文字平滑差异保留真实400字重。
