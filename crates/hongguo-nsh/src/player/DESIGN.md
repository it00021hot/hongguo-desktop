# 播放舞台

## 参照与边界

布局以 Tauri 的 `player-page.tsx`、`player-stage-chrome.tsx`、
`controls/player-controls.tsx`、`controls/scrub-bar.tsx`、
`interaction-rail.tsx`、`immersive-info-overlay.tsx` 和 `binge-entry-bar.tsx`
为参照，不将原生系统播放器控制条当作这套界面。

`stage` 是生产与离线预览共用的受控视图：视频/固定帧、信息、互动栏、
播放控件和状态分别进入同一个舞台。预览不创建 Session、数据库、原生视频或网络请求。
固定内容为「装穷提亲，娶到全家嫌弃的她」、第 1/80 集、暂停 00:42/02:49、
720P、1×、匿名。图片由调用者注入，预览标题的回调进入真实详情预览路由。

高级控件使用明确的操作意图和能力状态。离线对照呈现 Tauri 的可用状态；
生产中尚未具备的画质增强、小窗、弹幕设置、隐身、竖屏与无边框能力保持禁用。
这些静态控件的出现不代表业务功能已经完成。

## 几何与排版

| 区域   | 桌面规则                                                                      |
| ------ | ----------------------------------------------------------------------------- |
| 舞台   | 填满内容区、黑色底、视频 contain；叠层不占视频的 flex 高度                    |
| 控制栏 | 左右 16px、底 12px、两行间距 8px，不换行；溢出沿舞台裁切                      |
| 进度   | 16px 操作行，2px 白色轨道；已播放白 60%，其余白 20%；静止不显示 thumb         |
| 互动栏 | right 8px、bottom 96px、列 gap 16px；评论 glyph 32px，其余 28px；计数 12/16px |
| 信息   | left 12px、bottom 112px，外框 62%；简介行最多外框的 36%，保留展开按钮         |
| 观剧条 | 左右 12px、bottom 56px、40px 高、黑色 60% 底衬                                |

控件依序为播放、上集、下集、时间、弹幕输入/表情/发送、倍速、清晰度、增强、
选集及总数、下载、小窗、弹幕设置、弹幕开关、音量、隐身、竖屏、无边框、全屏。
只有弹幕输入整体收缩，按钮保持尺寸，不通过换行或删按钮改变 Tauri 的布局。

文字遵循共享播放器变体：一般文字 normal 400，标题 semibold；时间使用等宽字体。
季徽的 10px 字号、15px 行高、1px 上下间距和 2px 圆角是对应 Tauri 原组件的明确例外，
集中在 `ui`；颜色均消费 `video-*` 语义角色。

窄窗口保留右上倍速、底部时间/细进度和左下信息；手机触达尺寸由共享控件适配。
窄桌面截图不视为 Android/iOS 视觉验收。
窄屏分支精确对照 `PhonePlayerChrome`：右上 24px 黑35%倍速 pill、12px 等宽文字；
底部左右12px、上16px/下6px、时间10px/15px白70%与细进度间2px。
互动栏在窄屏也保持底96px，信息与观剧条沿真实原组件的底40px锚定。
480px 适配中，简介仍保留布局高度而不可见、不可聚焦，以免重叠观剧条。
Tauri 的 `ImmersiveInfoOverlay` 源码始终渲染简介，并不存在窄屏隐藏分支；实际参考图中
简介被后绘制的 `bg-black/60 backdrop-blur-sm` 观剧条遮蔽。NSH 原生 `backdrop_blur`
实测出现灰底且仍漏出简介，因此撤销该滤镜，使用 `visibility: hidden` 匹配实际遮蔽结果。
这是原生视图适配，不把它写成 Tauri 的业务条件。

## 状态与动效清单

本轮收口加入生产 Chrome owner：播放中静止 3 秒使用现有 200ms opacity 淡出，
视频内移动/真实输入重开倒计时，离开立即隐藏；暂停、控件悬停、键盘焦点与面板常显。
自动连播先静默，首个真实播放样本或用户操作解除；移动事件在首播前 8 秒内不唤醒。
保持原几何与一个显隐状态，隐藏层不拦指针；减少动态效果取消淡入淡出。
计时、暂停、焦点与面板优先级先用手动时钟回归，随后验证生产同一组件的明暗动效。

| 变化                     | 实现                                                     | 当前验证                                                    |
| ------------------------ | -------------------------------------------------------- | ----------------------------------------------------------- |
| 控件 hover/pressed/focus | 共享 `ui` 原生状态与动效角色                             | 共享控件已有回归；新舞台逐项互动仍待验                      |
| Chrome 显隐              | 共享 200ms opacity，隐藏时不接指针；减少动态效果取消过渡 | 静态展开状态已对照；闲置自动隐藏控制器待补                  |
| 视频换源                 | 来源 URL 作为稳定身份，只有换源才重建原生视频            | 进度/生命周期回归通过；新布局真播暂缓                       |
| 点赞/收藏                | 既有控制器乐观计数、失败回滚、提交禁用                   | 纯状态回归通过；真实账号写操作未自动执行                    |
| 简介展开                 | 受控双行/完整文字切换，不移动视频                        | 视图已接；展开后的视觉与大字体待验                          |
| 倍速/画质/选集菜单       | 共享 lazy sheet，关闭后同步受控状态                      | sheet 延迟构造/关闭/Escape 回归通过；播放器菜单完整交互待验 |
| 播放进度                 | 独立本地与云端 writer，离页/后台/完成 flush              | 慢云请求不阻塞本地保存及最终样本回归通过                    |

## 真实播放业务状态

`page` 与首页 `embedded` 复用单一生产控制器；嵌入者传入所属路由，首页不会因自己不是
`Route::Player` 被生命周期规则误暂停。系列解析与注册由嵌入者在挂载前完成。

原生事件按当前 lease URL 校验身份；旧源的 load/progress/buffer/error/end 不覆盖新源状态。
每个来源只消费首次 load 的续播点，后续元数据更新只更新长度。续点等于整集结尾或无效时从零开始；
显式画质切换使用本会话位置，同档或当前集重复选择不重置播放点。
自动画质传递既有 `PlayRequest.reset_definition`，并触发在线选择以清除旧手选记忆；
菜单依据实际 `automatic_definition`/active definition 表示当前模式，而不把局部 None 当作已自动。

对于增长来源，业务总长用于显示，实际 native duration 单独保存。可跳转范围取有效 native duration
与服务端内存中已发布 HLS 分片总长的较大值，不使用业务整集长度冒充可播范围；由原生 progress tick
驱动检查，不添加轮询或重载。目标可用后只派发一次 seek，实际 native 进度距目标一秒以内才确认。
暂停时没有原生 tick 也由来源 owner 的 readiness Resource 等待服务端增长条件变量，增量索引在后台
扫描；完成状态响应式唤醒 seek。改目标、切源或销毁 owner 取消旧 waiter；旧 Resource 值按目标 token
与 loading/error 状态隔离，不能提前派发新目标。界面线程不扫描文件，也不轮询。
等待期间视频透明并临时静音，保留解码/tick；不把目标伪写到显示值或历史。producer 已完成且 native
返回有限正总长后，目标越界才显式报错并暂停；已发布片段缓存不能证明最终边界。只有实际确认后的
进度才交给 recorder；暂停/后台刷出最近实际样本。

Apple 的 NSH 0.4 Video 没有公开 seek 完成/读当前位置接口，SDK 的 periodic observer 在暂停时不发进度。
平台门面仅为 macOS/iOS 标记此能力缺口。已实际 dispatch、用户暂停且来源/路由有效时启动单次确认窗口：
原生派生 rate0.25、采样50ms并暂时解暂停，仍隐藏静音；用户 paused/rate 与菜单不变。仅真实目标附近
Progress 可关闭窗口并恢复原生暂停，3秒未确认显式失败；改目标、离页、换源、错误或手动播放关闭旧窗口。
窗口及 pending 期间 ended 不完成记录、删除或自动切集；普通自动下一集也尊重用户暂停。
最新严格暂停原生 `Seek.test.tsx` 已通过：同第5集/154秒，87→98静止1.2秒→89静止1.2秒，恢复实际到91秒，
前后确认均断言缓冲提示消失。证据为 `target/nsh-playback/seek-buffer-end-results.xml` 与对应 live log。
此前 seek-confirmation 轮只独立断言前向保持，后向保持的旧报告有误；本轮新增后向断言补齐证据，旧红日志保留。

结束事件由独立门禁处理：未加载及重复事件忽略；增长来源需 producer 完成、实际进度已到
整集/原生长度附近（整秒元数据与采样允许一秒余量）才完成记录、自动删除及自动下一集。
早到的 ended 只刷出已播样本并保持缓冲，不把保护门禁当成已解决协议或起播问题。
向后 seek 的真实确认同样结束 seek/awaiting-more 状态，独立保留 native 仍报告的缓冲，避免暂停后缺少
下一次 tick 时残留提示。用户暂停时的 ended 在记录完播、自动删除及切集前忽略，防止确认后排队到来的
片尾事件消耗完成门禁；确认→暂停 End 与 onBuffer(false)→后跳确认均有离线先红后绿事件序列回归。

倍速、音量和静音由 SessionHandle 的单一 PreferenceSignals owner 持有，跨嵌入重挂/路由保持，
不会用进程静态状态混入另一会话。当前尚未持久化到重启后，也未新增共享 Settings/IPC 字段。
原生失败与准备失败共用可重试错误区；成功删除通知独立，避免被当作播放失败。
视频表面提供同一播放/暂停切换，触屏无需桌面控制栏；使用独立动态可访问标签“播放视频/暂停视频”，
交互与语义绑定独立视频槽 View，使用 BoxOnly 排除 hosted video 的原生命中；SDK 的 native picker
按 hosted view 矩形判定 native，不遵循 VideoLayerView 的 hitTest:nil，普通父 View 与 Video primitive
接线均已被真实 App 红测否定。视频槽不包 chrome/controls，不改变几何。仅当前来源且路由允许播放时响应。
独立 `VideoSurface.test.tsx` 原生回归通过：同集暂停40秒保持2.2秒不走时，恢复到42秒；标签随状态切换。

NativePrefix 重入在取流/取明文前加入同系列、集数、档位的活动生产者，竞争预留失败后再次加入；
Busy 不作为 ByteVC2 解码失败触发其他编码。会话拥有首段/终态的独立 Condvar，附件取消仅停止自己的
等待；同路径重开后旧 Arc 的等待和清理不影响新代。首段之前等待、失败/取消优先于已有字节、
完成时验证封存缓存；生产者刚完成并移除时仍可命中完整缓存。TauriPrefix 与 Complete 保留原交付方式。
缓存同时拒绝 Open/Failed/Cancelled 增长状态，即使取消与 seal 竞争留下标记，也不复用失败产物。

业务定向回归 `cargo test -p hongguo-nsh --lib player:: -- --skip player::stage` 本轮53项通过。
首段误完播、重复 ended、重复 load 回跳、同档/同集污染、自动画质 reset 均有先红后绿证据；
EVENT 原生 indefinite 但 published45 秒可续到42秒、published10秒需等候、seek仅发一次与真实tick确认、
结束后不可达目标报错均有先红后绿证据；拒绝换源时 Resource 保留旧值但不能继续播放有 Headless 回归。
会话 owner 替换后控制值保留通过 Headless 验证。菜单键盘与真实 native 播放单独验收，
暂停无 tick 的等待有离线先红后绿证据，另验证等待取消与旧结果不误放行；控制栏交互值在 pending
期间保留的回归见 [stage/DESIGN.md](stage/DESIGN.md)。真实同集指针 seek 已由独立 App 验证，
上述纯状态结果不等同于真实起播/seek/切集/倍速已通过。评论面板打开时循环本集、
跨重启控制偏好及同一来源结束后的手动重播仍需后续行为对齐与真实验证。
