# 弹幕显示与设置

规格来自 Tauri `use-danmaku-settings.ts`、`playback-prefs.ts`、`danmaku-layer.tsx`、
`controls/player-controls.tsx` 与 `phone-player-chrome.tsx`。

- SessionHandle 独占 DanmakuPreferences；开关与四参数读写 NSH Storage，同名键独立于 Tauri 数据根。
- 默认不透明度/字号/密度/区域为50/50/50/25%，范围分别为0.1–1、0.5–2、0–1、0.25–1，滑杆步长0.05。
- 损坏值回默认，有限越界值钳到范围；保存失败就地提示。fixture 状态只在内存，不调用Storage或账号API。
- 桌面设置为240宽、p16、圆角12、视频底色85%、向上间隔12；四行gap16。
- compact 的1x入口是同源 More sheet，包含倍速、自动/手选画质、弹幕开关与展开设置；设置行gap12。
- 独立启用弹幕设置，不能因此开启尚未支持的增强/小屏/隐身等按钮。弹层打开时暂停后台播放快捷键。

飞行采用平台无关、可注入的 NSH 单调时钟，固定9秒墙钟，不将媒体倍速乘进飞行时间。
每条飞行保留自己的泳道/字号与剩余时长；用户暂停、实际缓冲、seek等待或不允许播放时冻结，恢复继续剩余时间。
播放位置倒跳超过50ms或前跳超过1.5秒、切源/开关会清空旧飞行并重设入场位置，避免回放积压。
显式pending seek无论位移多小，先清旧cues并等待真实确认，再从真实当前位置建立新cursor；不借改视频源/轮询实现。
原生动画结束才删除条目，resource先交付完成值，effect再删除其owner行，避免回调向已销毁信号投递。
减少动态效果时固定位置显示，仍按相同可暂停时钟结束。
文字为600字重、单行、1px/3px柔和阴影；表情为同源inline图，不借字幕底衬假装弹幕。

字号基准按画面高/30钳15–22，再乘字号参数并保持最小10；泳道按区域高度/字号+10计算、至少4条。
泳道分配与原源一致选最早空闲者，入场占位1.4媒体秒；密度对新入场均匀抽样。
NSH采用稳定ID抽样，保证同一弹幕不因进度tick/重复分页反复切换可见性；修改字号/区域影响后续入场，
不重启已在飞的动画，不额外创建轮询重载。

回归包括真正生产Overlay的2×进度：旧实现墙钟5秒已消失为红，新实现5秒保留/9秒结束为绿；
同Overlay暂停11秒仍保留、恢复后只用剩余时间结束。测试使用公开NSH manual clock，无真实网络/账号写入。
另有游标/抽样/几何、参数持久化与错误存储、真实设置入口/四滑杆/关闭重开回流覆盖。
14项定向回归包含buffer持11秒与0.2秒显式seek（无原生tick即清空）的真实Overlay先红后绿，
并验证过期后页面仍可操作；不使用manual clock的wait-for推进到自然到期伪装小seek成功。
原生可视验证入口为 LayoutPreview 的 mod-shift-D，同生产stage与Overlay，仅注入假媒体时钟。
