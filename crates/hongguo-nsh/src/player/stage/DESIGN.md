# 播放控制交互

生产与离线预览使用同一受控菜单，媒体操作由外层业务拥有，stage 只派发意图。
菜单状态记录当前打开的一个面板；切换来源、加载与关闭事件由业务回流，不在控件内伪造播放结果。

| 状态变化                  | 工具与反馈                                                                                       | 减少动态效果                            |
| ------------------------- | ------------------------------------------------------------------------------------------------ | --------------------------------------- |
| 倍速/清晰度菜单打开与关闭 | NSH Menu 的锚定 popup/手机 sheet；popup 从触发侧淡入并轻缩放，关闭更快；Escape/外部点击回写 open | popup 立即显隐，原生 sheet 遵从系统设置 |
| 当前倍速/清晰度改变       | 语义 radio checked 和 Check 图标，选中背景 FAST_MS；数值即时回流                                 | 不做背景过渡                            |
| 清晰度取数/换源           | busy 时禁用；无档位时保留禁用入口；切换保持播放位置由业务负责                                    | 即时反馈                                |
| 选集面板/范围改变         | 有界虚拟网格；每 30 项一段，当前集显式选中；范围跟随真实集号，不合成缺集                         | 范围内容即时替换，不播放列表重入动画    |
| 点选剧集                  | 发 SelectEpisode；不关闭面板以便连续跳转；busy 时禁用，实际当前集由业务回写                      | 即时反馈                                |
| 音量面板与静音            | 锚定 Popover/手机 Sheet，数值和 Volume/Muted 图标由真实信号回流；0..100 slider 拖动 1:1 跟手     | 数值与 slider 不加缓动                  |
| 进度拖动                  | 手势期间保留局部预览值，松手才发 Seek；busy/来源变化取消拖动；键盘箭头使用同一命令               | 拖动始终 1:1，无额外动效                |
| 播放/暂停及上/下集        | 保留原舞台几何、语义名称、可见焦点、边界/加载禁用，hover/pressed 使用共享 token                  | 取消缩放/过渡                           |

键盘路径：Tab 到触发器，Enter/Space 打开；菜单箭头移动、Enter 选择、Escape 关闭。
选集网格可 Tab/Enter，音量/进度 slider 可用方向键。图标和选中状态不只依赖颜色。

Android 的 slider responder 与原生 press 分别分发：轨道响应 seek 后，原生 View 若不消费 press，
同一次点击还会穿透到兄弟视频层。进度条现有触摸范围由非焦点消费层接住 press；
seek 仍由 Slider 负责，横屏偏移跟随该消费层，不增加可见控件或额外 Tab 停点。
`seek_tests` 对原生 press 边界缺失先红后绿，并检查暂停/播放两种意图下拖动不翻转状态。
该回归不代替 Android 正式包同轨道位置点击复验，实际设备结果由集成记录保存。
验证须包含：当前项、自动清晰度、稀疏集号范围、同档/同集无操作、加载禁用、
menu dismiss 回写、slider/静音回流，以及生产和 fixture 共用视图的明暗开态截图。
系统屏幕阅读器及真机触控须独立验收，不能由无界面测试代替。

## 当前检查

菜单模型与实际控件分开验证：稀疏集号/分段边界/四向步进模型覆盖真实集号身份；
四项 Headless 控件回归覆盖倍速与自动/手动清晰度的 checked 回流、加载禁用、
每 30 项分组、连续选集、重开后当前集、音量键盘与静音。另已先红后绿验证原菜单
上下键会穿透至背景推荐流，补菜单焦点管理与仅打开时绑定的键处理后，面板内按键
不再切后台剧，关闭后背景按键恢复。

虚拟数字格使用 native Button 与显式当前选中，面板按真实 indices 处理左右 ±1、
上下 ±8 的移动并回写焦点；范围仍使用原生 RadioGroup。不会把 NSH 0.4 在虚拟格
内未生效的 RadioGroup 箭头当成已验收行为。菜单选择与弹层关闭交给基础组件，
app 的导航补充层负责当前项焦点、上下键和 Tab 关闭，关闭返回触发器。

延迟原生确认的 seek 回归先红后绿：旧同步在 Home→Right 时错误请求 21 秒，
加入业务 seek_pending 门禁并先派 Seek、再结束拖动后，请求正确保持 0→1；
时间文字仍显示真实原生位置，确认后下一次 Right 再请求 2，不靠 fixture 伪造进度。

stage现有9项定向回归通过（3模型、4菜单、延迟seek及真实控制条选集入口）；严格检查需与本轮其它模块最终批次统一记录。

圆角、字体层级、间距/对齐、明暗颜色、当前选中及可见焦点均已检查；hover/pressed
复用共享皮肤，未逐控件录制运动过程。弹层过渡完成态已见，减少动态效果在无界面回归

## Tauri菜单精确对照

选集弹层按原EpisodePicker布局：桌面460宽、至多视口62%高、上方12间隔，padding16；标题行是选集/系列剧双tab、红下划线、季数徽章、全N集与收起。范围是13px文字（非实心按钮），每30集一段；8列36高数字格、间距8，当前集红底，下载完成为右上角点。系列卡使用40×56封面、10内边距，当前季播放中、已上线季播放、未上线季预约/已预约；桌面toolbar持有唯一Popover，窄舞台持有独立受控Sheet，关闭返回真实More入口。横条只进入连播锁定，锁后隐藏，不再兼作选集触发器；隐藏横条不会销毁选集owner。

清晰度遵从用户最新要求只显示自动或NP，不附宽×高；选中勾在右侧。倍速/清晰度保留标准菜单焦点背景，outline与Tauri菜单一致隐藏。系列与菜单的新语义色来自theme，包含Tauri真实red-500/emerald-400的oklch值，不在功能页写调色值。

新增系列tab、范围文字选择、红数字格与预约按钮的hover/选中采用共享FAST过渡，减少动态效果时取消。计数、下载点、当前集和已预约反馈即时更新，不作数值动画。切季与预约派发真实意图，fixture以同一展示组件的本地状态实现，无官方API。

本轮完整原生明暗2/2通过，覆盖无尺寸清晰度、双tab/范围、连续选集、预约、切季及音量；共有10张开态图，新增`player-menu-seasons-{dark,light}-1280x840.png`。与同数据生产Tauri基准逐张比较：选集约x440/y512/w460/h272，Tauri约x441.44/y512.5/w460/h271.5；系列y376/h408一致。保留原生字体正确权重，不能把Web与CoreText字体平滑差异描述为完全像素一致。

最后`AlignmentFinishing.test.tsx`明暗2/2再次通过并亲自检查新图：菜单焦点采用Tauri背景反馈，系列卡半径10，质量选项与按钮均不出现宽×高。radius、字体层级、间距、对齐、语义颜色、选中与禁用状态已逐项核对；hover/pressed/focus由共享控件持有，键盘菜单/选集9项Headless回归通过。新系列意图生产已接controller，但本组离线预览不能证明真实账号预约、网络失败、Windows/移动端/屏幕阅读器可用，这些仍须各目标验证。
