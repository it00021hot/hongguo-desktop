# 剧终接力

规则来源为 Tauri `use-binge-relay.ts`：末集自动结束或用户向后越过末集，都优先接大于当前季的最小已上线季；无季标的旧响应保留已上线邻项回落；再走首页下一条，独立播放页才走猜你喜欢。下载面板阻止接力。评论面板的循环与自动下一集静默 Chrome 仍由 native/completion 的单一结束入口负责，本模块不重复处理。

季数规则已从 GPUI 上移到 `hongguo-common::model::season`。借用型 SeasonCandidate 不依赖 API 或 UI；返回原数组索引，两个 Rust 壳保留各自完整元数据。当前自身角标优先于标题中的中文/阿拉伯季数，服务端排序不决定下一季，0 集的未上线季不参与。NSH 系列菜单也复用同一严格角标解析。

Controller 拥有一份 Related Resource，系列菜单消费同一快照，只另取预约状态。SourceKey 包含当前剧、集号和原生媒体租约身份；请求还关联账号版本、用户暂停意图及 Feed 游标版本。离页、下载面板、换源、换账号、用户改变暂停意图或切换 Feed 上下文时，取消资源并拒绝旧结果。慢请求的重复结束只接管一次；先清当前请求再调用选中回调，避免新页面清理后继续读取旧 owner。

Related 刷新失败时先保留匹配当前剧和账号的已知快照；没有快照的首页仍按 Tauri 走下一条 Feed。独立页没有已知推荐时显示明确错误，不猜测剧目。此边界已由 Feed 未推进且暂停的真实失败转为资源回归通过。

下季与推荐使用共用 resolve_archive，不把历史最近一集误作接力首集；实际取档案中最小的真实集号，先登记到共享 registry。首页插入或定位目标剧，保留后面的原推荐和服务器分页状态，并用一次显式起集覆盖常规续播入口；离开该条后清掉覆盖，回看仍走正常续播。接下一季延续连播锁，成功刷下一条解除旧锁。

手动系列选择仍复用 resolve_start 的续播起点，回调交付已登记的完整 Series，使首页也能对齐 Feed 游标与连播锁。其异步 Resource 绑定包含 Feed 版本的 SourceEpoch、集号及账号；源变化立刻释放旧 busy 并取消读取，新请求无需等旧 HTTP 结束，旧完成不能清掉新 busy。此路径另有慢请求回归，不只比较几个字段。

自动结束的 Chrome quiet 提示由 Feed owner 持有绝对截止时刻，供新播放器 owner 消费一次。真实播放或显式输入清提示，手动频道更新清未消费提示；自动 goto/下一条仅保留紧邻更新的一次提示，既不重开八秒窗口，也不让旧提示影响之后的手动换剧。

业务回归使用固定 Related 与可控 oneshot resolver，不触网络、用户库或账号写接口。覆盖策略优先级、重复结束、首个真实集号、旧结果不清新 busy、账号/下载/暂停/路由/Feed 版本取消、失败释放以及 Feed/独立推荐分派。

2026-11-12 正式 App 独立 final-profile 的 Relay 用例实际退出0、1/1通过（38.3秒，含构建57.3秒）：《装穷提亲，娶到全家嫌弃的她》第80/80集128秒，真实暂停后定位125秒并保持，再播放到结束；接到《重生八零渔村带妻女赶海暴富》第1/160集，原生时间从2推进到4/204秒，最后暂停。日志、JUnit与截图在忽略的 target/nsh-playback/relay-*；该真实结束证据与上面的离线状态回归分别记录。
