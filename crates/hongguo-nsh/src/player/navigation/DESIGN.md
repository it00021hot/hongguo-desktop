# 舞台切换与连播

契约取自 Tauri `use-player-interactions.ts`、`binge-entry-bar.tsx` 和 `use-binge-relay.ts`。

- 滚轮垂直位移至少15点；触摸至少60点，且纵向至少是横向的1.5倍。上滑/向下滚为下一项。
- 滚轮与触摸共用400毫秒单调时钟闸门；键盘不占用它。闸门由首页 FeedNavigation 持有，切剧重挂播放器不会重置。
- 未锁定首页时切剧，锁定当前剧或独立播放页时切集。越尾由宿主 step_episode 回调统一接力，不在手势层吞掉。
- 横条只锁定当前剧，锁后隐藏；选集仍由独立的工具栏或更多入口打开。退出锁定由宿主在面板关闭、非输入状态下处理 Escape。
- 手势只绑定视频槽；控件、弹层与互动栏是兄弟层，不进入其触摸路径。面板、离页、失效源同时由当前 State 守卫。
- 触摸满足阈值后才认领，认领取消轻触播放/暂停；横向系统手势、取消与多指不切换。
- 桌面原生组件只在裸视频悬停、当前窗口及有效范围内发布滚轮，销毁时移除监听。macOS精准滚动保留点值，鼠标行乘10；Windows沿公开宿主的120单位、系统行数和每行16点归一。

动效：此域仅发布带方向的意图，不对手指位置造动画或修改媒体时钟；舞台过渡与Chrome由宿主持有。任意有效视频滚轮唤醒Chrome，即使未越过切换阈值；触摸仅在最终满足阈值时唤醒。减少动态效果由共享舞台表现层处理。

已验证五项定向回归：阈值/轴向、共享冷却边界、真实视频槽滑动、feed/锁定切集、面板/离页屏蔽、保留原轻触。Windows原生桥已交叉check；这不是Windows设备或macOS真滚轮验收。NSH测试驱动的macOS滚轮直接发送到窗口，不经过应用local monitor，不能把该自动化步骤冒充真实系统滚轮。
