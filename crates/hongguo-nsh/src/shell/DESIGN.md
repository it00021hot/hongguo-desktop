# 桌面退出确认与手机导航

桌面托盘采用独立的单色果实播放 SVG，不使用 Dock 的暖白底板；macOS 通过 NSH SVG 模板
随系统菜单栏切换前景色。托盘点击显示主窗口，菜单提供显示主窗口与退出；退出复用窗口
关闭确认，取消不关闭应用。托盘与菜单使用 NSH 原生接口，语言变化更新菜单，根 owner 销毁时释放。

桌面关闭按钮、Alt+F4 / Command-W 及窗口菜单关闭先由 NSH `close_on_press=false` 拦截，
`on_close_press` 打开唯一退出确认；Command-Q / 应用 Quit 菜单通过 NSH `on_quit_request` 接入同一确认，取消时调用 `cancel_quit_request`；重复关闭不叠加弹窗。使用现有共享 confirmation，
复用中英文退出文案、语义令牌、淡入和减少动态效果策略。取消或 Escape 只关闭弹窗，
确认后调用 NSH `quit` 退出；系统强制终止及注销/关机仍由系统直接退出（不阻塞系统请求）。
明暗主题、取消后再次关闭及确认退出仍需交互验收，不以编译检查代替。

推荐页的任务是直接观看和切换频道。手机隐藏推荐页的重复系统标题，安全区下只保留一行频道与固定主菜单入口：iOS 44pt、Android 48dp，频道文字16pt、单行、可横向滚动。主菜单不随频道滚动，沿用现有唯一 Sheet、页面入口、主题与语言选择。其他页保留系统标题、返回按钮和返回手势。

频道状态以文字与底部短前景色线表示；左侧固定主菜单、居中频道、右侧固定搜索，左右控件同宽。按压、焦点、hover 使用共享语义令牌，状态过渡使用 FAST_MS，减少动态效果时取消。频道切换复用既有数据/播放语义，搜索进入找剧；主菜单展开、关闭与焦点返回沿现有 Sheet 原生转场。

底部四个一级入口为首页、找剧、下载、我的。对照官方首页采用 NSH Tabs 的等宽文字导航，复用框架页签角色、选中状态和方向键行为；每项48pt，底部另加系统安全区，不再绘制图标及胶囊。根节点只处理顶部及横向安全区。底栏显示时不重复添加底部 inset；独立播放器或隐藏栏模式由手机壳补底部安全区。同组页签固定页面外壳，仅切换内容；我的统一承载账号信息和登录、退出，设置不再显示账号卡片。

无界面回归覆盖320pt窄屏触控高度、频道选中、显示原生栏时无额外底部 padding、进入独立播放器后补底部 inset、返回后恢复。Headless 无法验证 UIKit/Material 的 intrinsic 高度及玻璃外观；最终手机明暗截图、原生返回和主菜单真实点击由统一设备验证负责，未完成前不标为视觉通过。
