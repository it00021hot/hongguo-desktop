# 受控单选下拉

设置与合并候选共用此控件；调用方拥有值、禁用状态与 Change 回调。桌面用公开 Popover，触屏用底部 Sheet，保持 combobox / listbox / option 语义，合并页可注入原有触发器皮肤。

NSH 0.4 macOS 会先激活拥有焦点的可按控件，再分派快捷键。BaseSelect 的高亮没有移动原生焦点，因而 End 后的 Enter 再次按了入口。这里将焦点交给真实 Option，使用其 Press 提交，保留 Home / End、上下键、禁用项跳过、Escape 取消及受控 selected。选择或取消后返回原入口；点击外部时保留外部的焦点。

候选使用有稳定值 key 的 virtual_list，列表高度不超过窗口的 60%。键盘用数据索引滚动到尚未挂载的候选，目标行挂载后接收焦点。行重建读取当前 Position，不把首次 index 锁在回收 cell 中。默认行高桌面 32、触屏 48；颜色、圆角和焦点描边沿用共享主题。

动效由 Popover / Sheet 的公开生命周期负责；此修复不添加额外过渡或改变周边布局，减少动态效果遵循宿主。回归覆盖真实 Focus 命令、禁用项、取消、触屏返回与 1000 个候选的首尾回收；原生验证另由 MenuAudit 覆盖设置及合并的实际键盘提交。
