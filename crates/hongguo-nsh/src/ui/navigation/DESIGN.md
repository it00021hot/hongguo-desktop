# 手机导航与推荐频道

推荐页的任务是直接观看和切换频道。手机隐藏推荐页的重复系统标题，安全区下只保留一行频道与固定主菜单入口：iOS 44pt、Android 48dp，频道文字16pt、单行、可横向滚动。主菜单不随频道滚动，沿用现有唯一 Sheet、页面入口、主题与语言选择。其他页保留系统标题、返回按钮和返回手势。

频道状态以文字与底部主色线表示；按压、焦点、hover 使用共享语义令牌，状态过渡使用 FAST_MS，减少动态效果时取消。频道切换仍复用既有数据/播放语义；没有新增装饰或入场动画。主菜单展开、关闭与焦点返回沿现有 Sheet 原生转场。

底部五个一级入口继续使用系统 TabBar：iOS 原生玻璃和 Android Material 由系统绘制。容器不伸缩、不指定从3倍截图反推的固定高度；高度由系统 intrinsic measurement 提供。根节点只处理顶部及横向安全区。底栏显示时不重复添加底部 inset；独立播放器或隐藏栏模式由手机壳补底部安全区。

无界面回归覆盖320pt窄屏触控高度、频道选中、显示原生栏时无额外底部 padding、进入独立播放器后补底部 inset、返回后恢复。Headless 无法验证 UIKit/Material 的 intrinsic 高度及玻璃外观；最终手机明暗截图、原生返回和主菜单真实点击由统一设备验证负责，未完成前不标为视觉通过。
