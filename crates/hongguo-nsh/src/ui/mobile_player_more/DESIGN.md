# 窄屏播放选项

对照 `phone-player-chrome.tsx` 的 More Sheet：底部原生 Sheet、最高窗口 78%、顶部圆角 16，
背景为两主题固定的播放器深色；内容 p16、右侧留 48 给关闭按钮、分区间隔 20。
倍速三列两行；清晰度自动加可用档位，文字仅为「自动」或「720P」。
弹幕开关、展开设置、四项滑杆、选集、下载均绑定生产传入的原状态和动作，
不创建第二套速率、画质或弹幕偏好。尚无增强能力时增强行明确禁用。

| 状态变化  | 工具与令牌                                                                                       | 验收                                                                                                         |
| --------- | ------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------ |
| 打开/关闭 | nsh-base Sheet 原生平移与遮罩淡入，系统 Escape/返回/下滑关闭；减少动态效果即时                   | macOS 窄窗口明暗打开/Escape/重开通过；手势、移动系统返回、减少动态效果待验                                   |
| 分段选择  | 原生 RadioGroup，选中背景 white20%、未选中 white5%、hover white10%；共享 FAST_MS，减少动态效果 0 | 明暗实际点击 1.5x、Right 改 2x、清晰度/自动通过；真实换源由生产播放器验收                                    |
| 弹幕开关  | 受控 Switch，track/thumb 同播放器令牌；共享 FAST_MS                                              | 明暗实际点击通过，Headless 验证原 Signal 回流；过渡逐帧未验                                                  |
| 设置展开  | 真实条件渲染、Chevron 旋转90°；不额外插值内容高度，防止拖动滑杆位移                              | 明暗展开四项、关闭重开收起通过                                                                               |
| 四滑杆    | 复用 DanmakuSettingsState 同四个 Signal 与范围，数字即时更新、不插值                             | Headless 拖动回流通过；桌面 track 改为源 CSS 的 4px、label 16px 行高，修后明暗实图复验通过，下载行不再被挤出 |
| 选集/下载 | 先关闭 More，派发既有生产意图；不显示无效操作                                                    | 明暗由 More 关闭后打开唯一选集通过，下载派发 Headless 通过；移动真实导出待验                                 |

桌面窄窗口保留实际 Tauri 紧凑尺寸；Android/iOS 使用 48dp/44pt 最小触达与安全区。
内容只有一个有界 Scroll；颜色全部来自主题，不从浅色页面继承。

生产与离线 fixture 共用本组件、原 MenuState.open 的 Rate 面板状态和播放回调。
固定六档倍速由原 stage::menu_model 提供，UI 不复制；清晰度来自真实档位，完全不展示 width×height。
已运行 480×840 macOS 明暗原生两项，照片在 `target/nsh-preview/player-more-{dark,light}[-expanded]-480x840.png`。
真实生产 Tauri PhonePlayerChrome 的对应 Sheet 是默认 492px、展开最高 655.1875px，NSH 首图约493/655px，
主分区和 3 列倍速/5 列清晰度已对齐。字体平滑、颜色管理、焦点环与像素级圆角仍有原生差异，
不宣称完全像素一致；系统屏幕阅读器、触控、移动安全区/旋转和真实移动宿主未在此组验收。

最终受影响的桌面弹幕/窄窗口 More 明暗四项全部通过，记录在
`target/nsh-preview/danmaku-layout-final-native.log` 和配套 JUnit。
已目检 More 默认与展开的两主题四张图片，再对照真实 Tauri 同组件基准；
展开图在交互后为 2x/自动/弹幕关闭，初始基准为 1x/720P/开启，选择位置差异来自已执行动作。
