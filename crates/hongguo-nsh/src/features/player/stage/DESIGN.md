# 播放控制交互

桌面信息区、右侧互动栏和连播入口按播控栏的原生on_layout高度定位；播控与连播、连播与信息区各留8dp，剧名与互动计数的底边共用同一锚点。窗口变窄时沿实际控制栏高度更新，不再使用互不关联的固定bottom值。字号沿原比例，不新增位移动画；控件仍沿FAST_MS反馈和既有播控显隐，减少动态效果沿框架设置。
