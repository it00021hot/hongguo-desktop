# 红果 NSH 设计规范

播放器下载面板复用 Tauri 的底部全宽 Sheet：最高 80vh，16px 标题区域，
32px 快捷区间和八列集号，集号区域最高 256px。打开/关闭由 NSH Sheet
原生转场负责；快速选择和集号 hover/pressed 用 FAST_MS，减少动态效果遵循
共享控件令牌。输入错误保留上一次有效勾选，提交失败保留面板，重开回到当前集。
此新增状态的原生明暗截图与键盘关闭验证完成后才计入验收。

## 平台与任务

本轮覆盖 Windows、macOS、Android、iOS。核心任务是找剧、选集、观看和续播。
桌面保留清晰的导航与键盘操作；移动端以系统返回、触控和安全区为准。
Linux、Web 不在本轮交付范围。

## 视觉语言

桌面样式调整依据现有 Tauri `AppShell` / `AppSidebar` / `SeriesCardGrid`：
44px 顶栏、224px 展开侧栏（56px 折叠）、37px 导航行（行间距 2px）、14px 系统文字；
内容页内边距 24px。海报卡为 3:4、约 160–200px 宽、16px 网格间距，
标题单行；详情封面桌面 176px、手机 112px，设置最大内容宽 768px。
桌面保留应用全部已实现分区，账户入口贴底；手机继续使用原生导航栈和 TabBar。桌面宽度低于 768px 时隐藏侧栏，显示 50px 高、五等宽入口的底部导航。
壳层/按钮配色跟随现有 Tauri 中性语义角色，红色仅用于内容或交互本身已有的语义。

本次布局动效清单：侧栏折叠宽度沿共享快过渡，选中项背景沿共享按钮过渡，
内容不会因折叠重置数据；海报 hover 只改变边界/背景，pressed 加深而不缩放整行；
网格列数随可用宽度更新，不播放重新出现动画；详情选集仍按集 ID 复用。
减少动态效果取消上述过渡。布局使用同生产 presenter 的离线预览作明暗截图验收。

沿用红果的内容优先风格，主色用于当前操作，海报和剧名承担内容识别。
主题由 theme.json 定义，页面只消费语义令牌。共享控制只能从 src/ui 引入。
不引入装饰性渐变、大标题横幅或重复嵌套卡片。

文字使用系统无衬线字体；正文 14px、次要文字 12px、详情剧名 24px。播放器及卡片徽标的 10px 文字是源组件的紧凑层级例外，在共享 UI 内集中定义。
间距使用 NSH 的四点刻度。圆角由 theme.radius 派生：控件 8px、卡片 14px、胶囊 full，不在业务页面硬编码。
桌面控件使用紧凑密度；iOS 操作区域至少 44pt，Android 至少 48dp。
所有操作具有可访问名称、可见焦点、禁用和加载状态。

## 状态与动效

顶栏完整交互补齐：前进沿已有导航栈恢复后退历史，新导航清除前进分支；按钮可用状态即时更新。
置顶按 NSH 公开 WindowLevel 切换 Floating/Normal，选中图标沿 FAST_MS 变为主色；减少动态效果时即时。
前进/新分支有 Headless 红绿回归，系统窗口层级与明暗顶栏仍需原生验收。

动效常量集中在 ui/motion.rs，优先 opacity 和 transform，减少动态效果时关闭过渡。
hover 为弱背景反馈，pressed 深于 hover；disabled 不响应这两种状态。
加载、空态、错误都有文字与可执行的下一步；后台任务失败不只写日志。

## 验收

画面增强面板沿用 Tauri 的两个独立开关与 0–100 锐化强度；默认均关闭。
开关选中和 hover 使用播放器语义令牌及 FAST_MS，面板展开/收起使用共享浮层动效；
reduce motion 时取消过渡。强度拖动只更新参数，不重建视频或增强模型。
准备、成功与回到原画均有可读状态，不以开关状态代替真实 GPU 状态。

手机横片的全屏观看入口位于 contain 画面底边下方 10px 的黑边，随真实舞台/视频尺寸更新；
进入横屏后用返回/标题顶栏与进度、弹幕、输入、倍速、清晰度、选集底栏。
方向变化由宿主确认后切换壳栏，不重建视频；控件显隐沿用 CHROME_MS、按钮沿用 FAST_MS，
减少动态效果时关闭过渡。退出后恢复原导航与同一播放状态。

榜单/新剧新增清单：榜单由内容分类、子榜、筛选和月份四个独立选择项驱动，
每次变更重置会话游标与列表，分页只追加新窗口，不重播整个列表。
筛选在桌面使用各自锚定的 Popover，手机使用底部 Sheet，面板与遮罩沿原生转场进出，
Escape/系统返回/关闭按钮回到触发按钮。新剧的推荐/日历、频道和日期切换保持
各自游标与滚动身份；预约按钮乐观切换，失败回滚，执行时禁用；匿名点击进入登录。
到达的列表状态即时呈现。推荐、榜单与非空日历已作同源明暗原生截图；真实账号预约请求与在线分页另验。

播放器社交操作清单：点赞、收藏、追更复用共享按钮；选中背景用 FAST_MS 过渡，
pressed 沿共享缩放，减少动态效果取消过渡和缩放。计数按已确认的用户操作立即 ±1，
失败回滚并显示重试，提交期间禁用。初始状态未到前显示加载；匿名操作先引导登录，
完结剧隐藏追更。此组交互尚待运行与视觉验收。

视频舞台以唯一来源地址为身份：同一来源的进度不重建舞台，换源才卸载旧原生视频并
挂载新视频。离页关闭通道后串行完成最终进度落盘，隐藏时立即刷盘。原生端换源时的
视觉连续性和音频停止仍需实际播放验收。弹幕使用独立视频字幕语义角色，单行测量，
不参与舞台的 flex 分配。

导航与表单补充清单：桌面一级入口按实际当前路由选中，详情等次级页不保留父栏目高亮，
返回首页移除上层路由；选中背景沿共享按钮过渡，减少动态效果时即时切换。
移动端使用系统 TabBar 保持五个一级入口，系统导航栈负责返回转场。
手机系统标题栏的主菜单按钮展开唯一底部 Sheet，复用桌面十三个既有页面入口，
补齐收藏、新剧、维护等页面可达性；这不是 Tauri 现有手机 Sheet（其侧栏与开关在窄屏均隐藏）。
按钮为 iOS 44pt/Android 48dp，菜单行48pt、正文16pt，长列表由真正 Scroll 视口承载。
打开/关闭用共享 Sheet 的原生遮罩与位移动效，按压与选中沿共享 FAST_MS；减少动态效果沿组件策略。
系统返回/Escape只关闭菜单并返回触发器，选择页面先关闭后导航；外部路由变化关闭旧菜单。
主题与语言位于主菜单固定页脚，与十三个导航项的 Scroll 分离；复用共享 Select，
手机选项仍由底部 Sheet 承载，子选择关闭后保留主菜单。保存主题时禁用重复选择，
配色与语言只调用既有壳层保存/翻译状态，选项与桌面菜单同源；选择及面板转场遵循共享动效。
此条先做可达性/返回行为回归，再以最终手机验证包检查真实标题栏与面板，不以属性存在代替画面。
设置由单一表单滚动区承载；登录入口共用短信/MFA 模态面板，缺少提示上下文时保留账号页回退。
键盘占用空间由外层跟随原生键盘 inset，滚动时可收起键盘，提交按钮保持可达。
上述变化先做行为回归，再验收明暗主题与宽窄窗口。

下载任务新增的变化包括进度、暂停、恢复、停止、重试与失败反馈：按任务 ID 复用行，
使用共享按钮的按压动效，操作执行时禁用。账号页覆盖发码倒计时、登录和 MFA
等待/失败/取消：保持输入焦点，异步期间禁止重复提交，反馈文字跟随真实结果更新。
历史/任务的明暗固定状态已截图；账号登录/MFA 与真实下载状态转换仍须独立验收。

逐页检查明暗主题的圆角、字体、间距、对齐、颜色、hover、pressed、其余状态和动效。
另查最窄窗口、移动端安全区、长译文、大字体、减少动态效果及键盘完成主流程。
无界面测试只证明行为；真机播放器、文件授权、屏幕阅读器和视觉效果需独立验收。
