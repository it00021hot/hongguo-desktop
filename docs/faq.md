## 一、播放有声音、没画面（缺 HEVC 视频扩展）

**原因**：视频是 H.265（HEVC）编码。Windows 播放 HEVC 依赖系统的「HEVC 视频扩展」，
不少旧版 Win10 没有预装——缺了它就是「声音正常、画面全黑」。macOS 版不受影响。

**系统要求**：Windows 10 1709（1803 更稳）及以上；更老的系统请先升级。

### 方式一：应用内一键修复（推荐）

打开任意剧集进入播放页，应用检测到缺扩展会弹出引导卡，点「一键安装」即可——
应用会自动下载扩展、校验完整性并安装，完成后点「重试播放」。
若重试仍无画面，重启一次应用再看。

### 方式二：手动下载安装

1. 下载扩展安装包（约 2.4 MB，Gitee 直链，国内可直达）：
   <https://gitee.com/it00021hot/hongguo-desktop/raw/main/HEVC视频扩展-双击安装.appx>。
2. 下载完成后双击 `.appx` 文件，按系统弹窗点「安装」。
3. 装好后**重启应用**即可正常播放。

双击没反应？你的系统可能没装「应用安装程序 (App Installer)」，改用 PowerShell：
按 `Win + X` 选「Windows PowerShell」，粘贴下面这行（把路径换成你实际的下载位置）回车：

```powershell
Add-AppxPackage -Path "$HOME\Downloads\HEVC视频扩展-双击安装.appx"
```

### 方式三：微软商店（官方渠道，付费约 7 元）

在「Microsoft Store」搜索「HEVC 视频扩展」购买安装，或直接打开：
`ms-windows-store://pdp/?ProductId=9N4WGH0Z6VHQ`

## 二、应用无法启动 / 提示缺少 WebView2

**原因**：应用界面依赖微软的「WebView2 运行时」。Win10/11 大多已自带；
没有时，**安装包在安装阶段会自动联网下载安装**，一般无需手动处理。

若自动安装失败（网络受限或微软源不通），手动安装任选其一：

1. **国内镜像备用包**（约 1.8 MB，Gitee 直链，国内可直达）：
   <https://gitee.com/it00021hot/hongguo-desktop/raw/main/MicrosoftEdgeWebview2Setup.exe>。
   下载后双击 `MicrosoftEdgeWebview2Setup.exe`，装完**重启应用**。
   注意：这是引导器，安装时仍需联网从微软下载运行时本体；完全离线的机器
   请在联网环境下载微软官网的「Evergreen Standalone 安装器」拷贝过去安装。
2. **微软官方在线安装器**（Evergreen Bootstrapper）：
   <https://developer.microsoft.com/microsoft-edge/webview2/>

装完仍提示缺 WebView2：确认下载的是对应架构（绝大多数电脑选 x64），再重启电脑试一次。

## 三、杀毒软件报毒、防火墙弹窗

- **杀毒报毒**：应用未购买代码签名证书，部分杀软会误报。请在杀软中将应用所在文件夹
  加入信任/白名单后重启应用。
- **「是否允许访问网络」弹窗点了取消**：播放依赖本地回环服务（`127.0.0.1`，只在本机
  内部通信、不外发数据），被防火墙拦住会提示「无法连接本地播放服务」。到
  「控制面板 → Windows Defender 防火墙 → 允许应用通过防火墙」勾选本应用（专用和公用
  都勾），重启应用即可。
