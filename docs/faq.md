## 一、播放有声音、没画面

NSH 客户端使用内置 HEVC/ByteVC1/ByteVC2 解码。系统媒体只负责音频和时钟；
播放不依赖系统 HEVC 视频扩展，不提供兼容转码或扩展安装接口。

先检查播放器显示的错误，再核对日志中的解码与 GPU 呈现状态。窗口被完全遮挡、
最小化或系统锁屏时，Metal 可能无法取得 drawable；仅有音频进度不能证明视频已呈现。
应在应用窗口可见时复现，并记录平台、清晰度、编码与具体错误。

不保留本地 H.264 系统播放例外。下载记录中的旧 H.264、缺失或无效文件会重新获取在线原流；
显式打开不支持、无法解析或缺少视频轨道的本地文件会明确报错。

合并可选择同规格原流无损直拼，或将混合素材统一编码为 HEVC；不输出 H.264。
HEVC 编码能力按实际试编结果检测（能力字段 `hevcHwEncoder`），不等同于播放解码能力。
没有可用 HEVC 编码器时仍可播放和无损直拼，但不能统一编码合并。

## 二、杀毒软件报毒、防火墙弹窗

- **杀毒报毒**：应用未购买代码签名证书，部分杀软会误报。请在杀软中将应用所在文件夹
  加入信任/白名单后重启应用。
- **「是否允许访问网络」弹窗点了取消**：播放依赖本地回环服务（`127.0.0.1`，只在本机
  内部通信、不外发数据），被防火墙拦住会提示「无法连接本地播放服务」。到
  「控制面板 → Windows Defender 防火墙 → 允许应用通过防火墙」勾选本应用（专用和公用
  都勾），重启应用即可。
