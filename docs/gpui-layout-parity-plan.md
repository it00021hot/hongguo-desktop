状态：已确认并实施（2026-10-14）。确认结论：侧栏 12 项全列出（缺页给

## 一、差距清单（GPUI 现状 vs Tauri）

### 1. 壳骨架

| 部位 | Tauri | GPUI 现状 |
| --- | --- | --- |
| 侧栏 | 12 目的地（首页/找剧/排行榜/新剧/历史/收藏/点赞/预约/任务/合并/存储/设置）+ 可折叠 224↔56px 图标栏 + 贴底账户区（头像/登录） | 固定 243px 文字栏，仅 首页/排行榜/登录 三项 |
| 顶栏 | 44px 横贯全宽：**分类 tab 居中（各页 portal 进槽位）**、置顶/主题/窗口钮居右（Tauri 顶栏左侧实际为空） | ✅ 已闭环：44px 自绘顶栏，tab 槽/置顶/外观/窗口钮/拖窗/双击最大化全对齐（2026-10-17，`aa54522`；见 `gpui-feature-parity.md`「顶栏结构」） |
| 播放区 | 内容区全量沉浸（顶栏下、侧栏右），视频随窗口连续 reflow | 结构相同但 243px 侧栏挤占 + 分类 tab 占舞台顶行，画面明显小于 Tauri |
| 弹幕输入 | 控制栏内 输入框 + 表情入口 + 发送按钮 | 仅输入框（Enter 提交），无表情/发送按钮 |

### 2. 悬浮层显隐状态机（chromeShown）

Tauri `usePlayerOverlay` 四规则（B 站方案）+ 一个总闸：

1. 画面内移动/点击 → 亮，静止 **3s** 收；
2. **指针离开舞台 → 立即收**（不等倒计时）；
3. **悬停控制栏本体 → 不倒计时**（拖进度条/悬停音量时永不收）；
4. 暂停常显；任一面板开（选集/评论/弹幕设置/音量）常显；
5. 自动连播切集**静默起步**（新集首播或真实输入前，一切悬浮层不亮）。

GPUI 现状：只有 3s 计时 + 暂停常显 + 选集浮层常显。缺：规则 2、3；评论/
弹幕设置/音量面板不计入常显；无连播静默起步。

### 3. 互动栏（右缘竖排）

GPUI 已有四键（收藏/评论/点赞/分享）+ 档案公开计数，差异：

- 计数格式：Tauri 抖音系阶梯 `≥100万 → "4.4百万"`、`≥1万 → "52万"`；GPUI 是
  `亿/万` 两级（440万 ≠ 4.4百万）。
- 分享键：Tauri 显示文字「分享」，GPUI 显示计数。
- 评论面板打开时互动栏**让位隐藏**（GPUI 未做）。

### 4. 信息叠加层（左下）

Tauri：`@剧名`、`第N集·全M集`、热度、简介超 40 字可「展开/收起」。GPUI 已有
主体，需比对补 @ 前缀与展开/收起交互。

### 5. 全屏

GPUI 全屏保留顶栏+侧栏+分类 tab（假全屏）。Tauri 全屏同样保留 chrome——
但按用户定调，GPUI 要做**真沉浸**：全屏藏全部 chrome，视频铺满整屏，
控制条照常悬停呼出，Esc 退出。（与 Tauri 行为有意分叉，待确认。）

## 二、实施步骤

**第一步 壳骨架**（本计划的核心结构改动）
- Shell 列结构：TitleBar（44px，refine 高度）+ [侧栏 | 内容区]。
- 侧栏重建：折叠态 56px 图标 + tooltip，展开 224px 图标+文字；12 目的地中
  已有页（首页/排行榜）真数据，缺页按确认的处理方式落位；贴底账户区
  （头像/登录，登录面板已有）。
- 分类 tab 从舞台顶部移入顶栏中部插槽（首页两 tab；排行榜页后续自带）。
- 顶栏补 置顶/主题 入口（待确认范围）。

**第二步 悬浮层显隐状态机**
- HomeView 增 `controls_hovered` / `pointer_on_stage` / 静默起步位；
  `controls_visible()` 改为 Tauri 同款裁决；控制条根元素挂 hover 置位；
  舞台 `on_hover` 离开即收；连播切集时静默起步。

**第三步 互动栏 / 信息层 / 控制栏细节**
- `fmt_count` 对齐抖音阶梯；分享键改「分享」；评论面板开让位；
- 信息层 @ 前缀 + 简介展开/收起；
- 控制栏补 上一集/下一集；弹幕输入加表情入口与发送按钮（表情选择器已有组件）。

**第四步 全屏真沉浸**
- Shell 读 `window.is_fullscreen()`：全屏藏 TitleBar/侧栏（tab 随顶栏走）；
  Esc 已绑退出全屏；退出后 chrome 恢复。
