# NSH 与 Tauri 功能对齐记录

本记录以现有 Tauri 页面和用户操作为验收对象。复用同一业务内核、编译通过或控件截图
不能代替功能对齐；“已接入”表示代码链路存在，尚不代表四个平台都通过真实运行。
Windows/macOS 的桌面能力和 Android/iOS 的系统交互分别验收。Linux/Web 留待后续版本。

## 持续对齐（2026-11-13）

- PR #23 的播放路径现统一为内置 HEVC/ByteVC1/ByteVC2 解码，本地 H.264 保持系统播放。
  NSH 四端消费共用解码会话的 BGRA 帧，系统媒体只读取原 MP4 音轨视图并提供时钟；
  兼容转码、增长 MP4/HLS 供数与兼容进度事件已删除。下文早期兼容播放与系统视频输出
  的验收记录属于历史证据，不能替代新路线验证。现行契约与验证边界见
  [内置解码接入说明](nsh-softdec-integration-plan.md)。
- 追更提醒接入本地列表、手动检查、未读计数、标已读、清空和通知开关，
  继续复用已有 follow service。检查任务由 Session 持有，订阅就位后仅启动一次，
  会话结束时取消。提醒行为、键盘操作及独立数据库的8项 service 回归通过；
  明暗原生预览发现的角标换行、开关标签换行和反馈挤动布局已按 Tauri 修正。
- Android/iOS 下载完成文件及合并成品接入系统导出，下载按当前任务 ID 解析文件，
  拒绝未完成、无路径和缺失文件。5项定向 Rust 测试通过；Android 实际取消/失败/保存
  流程通过，iOS 实际取消和保存流程分别通过。两端262144字节导出样本的 SHA-256
  均与源文件一致。iOS 保存按钮未暴露给 XCTest，采用已目检的自有模拟器坐标点击，
  再检查原生成功回调和实际落盘文件；失败的选择器尝试保留。
- 系统通知通过本壳平台适配接入，开启时才申请权限。Android 独立生产组件验证了
  拒绝、允许、实际通知展示及点击回前台；Apple、Windows 的实际系统展示尚未验收。
  通知所有权、乱序回执及并发上限3项回归通过。移动端仅提供本地通知，
  不承诺进程被挂起或终止后继续轮询红果接口。

## 当前验收优先级

当前先完成 Tauri 全页面与操作对齐，使用同数据原生预览逐页复验，再复验正式播放入口。
起播、暂停、实际倍速比例、切集、清晰度和续播分别取得运行证据，不能只检查按钮响应。
预览继续使用同一组固定数据、相同窗口尺寸和主题，复用生产页面的展示组件；
通用控件拼盘、只有代码链路和构建成功均不计作页面对齐。

桌面顶栏横贯全窗，高 44px；侧栏从顶栏下开始，展开 224px、收起 56px。
首页是铺满内容区的沉浸播放器，频道在全窗顶栏居中，**不是海报网格**。
找剧才使用搜索、筛选与海报网格；详情和设置各自遵循原页面的分区与内容宽度。
逐页比较布局、间距、字体、颜色、控件和状态，修正预览差异后再恢复业务验证。

### 正式播放验收

正式首页已从旧海报目录切换为共享沉浸播放器。离线舞台与正式入口共用展示层，
业务继续调用已有 service/API；离线静帧不计作起播证据。

本轮修复包括：短前缀误完播、旧来源事件污染、换源重复续播、切回自动画质未清手选记忆，
以及松开进度条后旧位置覆盖尚未确认的跳转目标。进度只在原生确认后显示和保存；
等待定位期间隐藏并静音视频，避免从头漏出音画。暂停时等待新片段由可取消后台资源唤醒，
不依赖暂停后不会继续产生的时间推进事件。

NSH 0.4 的 Apple 播放器没有公开的定位完成回调，暂停时也可能不回报进度。因此实际派发
跳转后，仅在暂停期间进行一次隐藏、静音的低速原生进度确认；收到真实目标位置即恢复暂停，
最长 3 秒，超时明确报错。用户的暂停与倍速选择保持不变，不重发跳转、不伪造位置；确认期间
收到结束事件不能记完播、删除缓存或切下一集；确认后排队到达的结束事件也受用户暂停状态保护。
向后跳转的真实位置确认同样结束定位等待，保留播放器本身尚未解除的缓冲状态。

转码未完成时从历史重新进入，NativePrefix 会加入同集同档位的原生产者；首段前等待可取消，
取消一个等待者不会停止原转码。Busy 不再被当作 ByteVC2 解码失败触发编码回退。
会话身份、完成封存与取消代际均有回归，完整 service 单测沿现有 CI 约定串行运行，
避免原有离线 QA/故障注入测试互相改写进程环境。

Apple 的增长中 MP4 经标准 EVENT HLS 供数，分段按实际关键帧闭合；初始化副本满足
HLS 时长约束，原始完整 MP4 保留自己的时间线。Android 已用 `MediaDataSource` 读取增长中 MP4，
并取得上方独立正式包的真实 ByteVC2 渐进起播证据；Windows 仍等待成功成片。
